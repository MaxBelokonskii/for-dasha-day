# Дашин день 💌

Интерактивная страничка-подарок: 13 экранов «идеального дня» — от утреннего кофе до ночного букета, параллакс, мини-игры и своя музыка (синтезируется в браузере, без аудиофайлов).

## Запуск локально
```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```
Можно и просто открыть `index.html` двойным кликом.

Отладка: `?s=4` в адресе открывает сразу 5-й экран (нумерация с 0).

## Публикация на GitHub Pages
1. Создай репозиторий и залей туда содержимое этой папки.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту страница будет на `https://<логин>.github.io/<репозиторий>/`.

Сборка не нужна: чистые HTML/CSS/JS, все пути относительные, есть `.nojekyll`.

## Что где менять
- `js/content.js` — подпись, тексты книги, товары «Любимаркета», фразы в поиске.
- `index.html` — заголовки и подсказки экранов.
- `assets/img/` — сжатые фото (≤800 px), их и грузит страница: `dasha.jpg`, `dasha-ray.jpg`, `ray.jpg` (книга), `us.jpg` (финал), `lissabon.jpg` (экран с котом).
- `assets/photos/` — оригиналы, в git не попадают (`.gitignore`). Новое фото сжать: `sips -s format jpeg -s formatOptions 74 -Z 800 оригинал --out assets/img/имя.jpg`.

⚠️ Репозиторий для GitHub Pages на бесплатном плане публичный — фото в `assets/img` будут видны всем, у кого есть ссылка (и в самом репо).
- `js/music.js` — музыка: аккорды `PROG`, мелодия `MELODY`, настроения экранов `MOODS`.
